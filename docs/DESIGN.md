# 静答 QuietAnswer · UI 设计方案 & 署名规范

> 面向现在的 `chaoxing-ai`（v1.9.1）改造。目标是：**低调、不打扰、状态一眼看懂、出事能自查**。

---

## 一、命名与署名

### 1.1 名字候选

| 方案 | 中文名 | 英文名 | 气质 | 备注 |
|---|---|---|---|---|
| **A（推荐）** | 静答 | QuietAnswer | 低调、安静地替你作答 | 与"最小化成窄栏"的产品哲学一致 |
| B | 答尔 | DaEr | 轻、有点憨 | 记忆点强，但偏萌系 |
| C | 墨隐 | InkVeil | 内敛、书卷 | 适合做成系列（墨隐·答题 / 墨隐·批注） |
| D | 学伴 | StudyMate | 中性、正向 | 太常见，商店重名风险高 |
| E | 解手 | — | — | 谐音不雅，弃 |

**推荐 A：`静答 QuietAnswer`**

- 中文 2 字，扩展名不超长；英文可作包名 `quietanswer`
- 与"判卷模式""最小化窄栏""不覆盖你手填"的克制定位一致
- 副标题固定为：**「学习通 · 判卷式答题助手」**

### 1.2 署名方案（三层）

**① 视觉署名（用户可见）**

```
静答 QuietAnswer
by YG · v1.9.1
```

- 出现在：工具栏弹窗底部、设置页「关于」区、扩展详情页
- 字号比主标题小一档、颜色降一档（`#8A8F9B`），不抢注意力

**② 元数据署名（商店/管理器可见）**

```json
{
  "name": "静答 QuietAnswer",
  "short_name": "静答",
  "version": "1.9.1",
  "author": { "email": "you@example.com" },
  "homepage_url": "https://github.com/YOU/quietanswer",
  "description": "学习通/超星 · 判卷式答题助手：先判对错，错的才改。"
}
```

**③ 代码署名（开发者可见）**

每个源文件头统一：

```js
/*!
 * 静答 QuietAnswer v1.9.1
 * 学习通/超星 · 判卷式答题助手
 * (c) 2026 YG · MIT License
 * build 2026-11-16T17:40:00+08:00 · sha 4f2a91c
 */
```

打包时由脚本自动注入时间与 commit，避免手改漏改。

### 1.3 图标与识别

- **形状**：圆角方块 `24%` 圆角（与现有 HUD 圆角呼应）
- **主图形**：深蓝底 `#2F6FEB` + 白色对话气泡 + 右下角绿色对勾 `#2FBF71`
- **尺寸**：16 / 32 / 48 / 128，16px 下**只保留气泡轮廓**，去掉对勾（太小会糊）
- **浅色模式变体**：白底 + 蓝描边气泡，供系统浅色主题使用

### 1.4 版本与渠道

| 项 | 规则 |
|---|---|
| 版本号 | 语义化 `MAJOR.MINOR.PATCH`，bug 修复 +PATCH，功能 +MINOR |
| 构建标记 | `1.9.1+build.20261116.4f2a91c`，只出现在日志与「关于」 |
| 更新日志 | `CHANGELOG.md`，每版一节，标题格式 `## [1.9.1] - 2026-11-16` |
| 许可证 | MIT + `NOTICE.md`（列出第三方依赖：`jsdom`、`playwright-core` 仅测试用） |

## 二、视觉系统（Design Tokens）

### 2.1 色彩

| 语义 | 深色（默认） | 浅色 | 用途 |
|---|---|---|---|
| 主色 | `#2F6FEB` | `#2F6FEB` | 主按钮、进度环 |
| 成功 | `#2FBF71` | `#1F9D5A` | 判卷正确、已完成 |
| 警告 | `#F5A524` | `#C97A05` | 跳过、低置信度 |
| 危险 | `#E5484D` | `#D0353A` | 出错、判卷错误 |
| 面板底 | `#1E2027` | `#FFFFFF` | 面板背景 |
| 页面底 | `#16171B` | `#F7F8FA` | 弹窗背景 |
| 描边 | `#2A2D36` | `#E4E6EB` | 分割线、输入框 |
| 主文字 | `#EDEEF2` | `#1A1C20` | 标题、正文 |
| 次文字 | `#8A8F9B` | `#6B7280` | 说明、署名 |
| 等宽 | `ui-monospace, Consolas` | 同 | 日志区 |

> 现有 `#7ee0a1` 这种荧光绿在深色底上偏刺眼，统一换成 `#2FBF71`。

### 2.2 字号与间距

| 层级 | 字号 / 字重 | 用途 |
|---|---|---|
| 面板标题 | 13 / 600 | 「静答」 |
| 正文 | 12 / 400 | 按钮、选项 |
| 说明 | 11 / 400 | 提示、署名 |
| 日志 | 11 / 400（等宽） | 运行记录 |

间距用 4 的倍数：`4 / 8 / 12 / 16 / 24`；圆角 `10`（控件）、`14`（面板）；阴影 `0 8px 28px rgba(0,0,0,.35)`。

## 三、组件设计

### 3.1 页面内 HUD（三态）

**状态 A · 折叠胶囊（默认新装时）**

```
┌─────────────────────┐
│ ◉ 静答   3/31   ⌃   │     48×168，贴右下角
└─────────────────────┘
```

- 左侧状态点：灰（空闲）/ 蓝呼吸（运行中）/ 绿（完成）/ 红（出错）
- 中间 `3/31` 是进度，不写"已答 3 题"省空间
- `⌃` 展开，`×` = 最小化成 8px 贴边细条（不是消失）

**状态 B · 展开面板**

```
┌──────────────────────────────────┐
│ ◉ 静答              3/31   ⌄  ×  │  头部：拖动区
├──────────────────────────────────┤
│ [ ▶ 开始 ] [ ⏸ ] [ 🔍 只扫描 ]    │  主操作
│ 模式  (判卷) 跳过   覆盖          │  chips，当前高亮
├──────────────────────────────────┤
│ #8  已有「D」→ 判卷…             │
│     ✖ 错误，改为 A               │  日志：按语义着色
│ #9  已有「A」→ ✔ 正确，保留       │
│ #10 [single] 选项匹配中…          │
├──────────────────────────────────┤
│ ● deepseek-flash · 正常   最后 12s │  状态条
└──────────────────────────────────┘
```

- **进度环**替代文字百分比：`3/31` 外圈一道 2px 环
- **模式 chips** 直接可切，不用进设置页
- 日志按语义前景色：成功绿 / 警告黄 / 错误红 / AI 原始返回蓝
- 底部状态条：接口连通性（绿点）+ 模型名 + 最近一次请求耗时

**状态 C · 单题模式**

只处理当前视口内的题（`IntersectionObserver`），日志显示 `当前题 12/31`，适合长卷子边看边答。

### 3.2 交互补充

| 交互 | 说明 |
|---|---|
| 拖动 | 头部拖动，位置记忆，越界自动钳回可视区 |
| 双击标题栏 | 折叠 / 展开 |
| `Alt+Shift+S` | 开始 / 暂停（可在 `chrome://extensions/shortcuts` 改） |
| 最小化 | `×` 变 8px 贴边竖条，鼠标移上去滑出 |
| 错误自愈 | 连续 3 题失败 → 面板自动展开并高亮错误行 |

### 3.3 工具栏弹窗

```
┌─────────────────────────────┐
│ ◉ 静答            v1.9.1    │
├─────────────────────────────┤
│ ● 接口   deepseek-flash 正常 │  点右侧「改」
│ ● 页面   已注入 · 31 题      │  未注入时红字「按 F5 刷新」
├─────────────────────────────┤
│ [    ▶ 开始答题    ]        │
│ [ 🔍 只扫描 ]  [ ⚙ 设置 ]    │
├─────────────────────────────┤
│ by YG · MIT · 关于           │
└─────────────────────────────┘
```

- 两个状态卡：**接口**（模型 + 连通性）和**页面**（注入状态 + 题数）
- 「开始答题」在未注入时禁用并提示刷新，不再点了没反应

### 3.4 设置页

左侧锚点导航 + 右侧分组卡片：

| 分组 | 内容 |
|---|---|
| 接口 | 预设 chips（DeepSeek Flash / V4 Pro / Ollama / LM Studio）+ 地址 + Key + 模型 + 测试连接 |
| 答题行为 | 自动填充、自动下一题、自动交卷（红色警示）、间隔、上限 |
| 已有答案 | 判卷 / 跳过 / 覆盖 + 最小置信度滑块 |
| 高级 | JSON 模式、思考模式、推理强度、自定义选择器 |
| 关于 | 名称、版本、构建、许可、致谢、免责 |

**安全设计**：`自动交卷` 开关旁常驻一行红字「会直接提交作业，请确认」；打开时二次确认。

| 位置 | 内容 |

## 五、落地顺序（建议）

1. **T1（半天）**：换名 + 图标 + 署名三件套（manifest / 弹窗底 / 关于区）+ `LICENSE`/`NOTICE`
2. **T2（1 天）**：HUD 三态改造（折叠胶囊、模式 chips、状态条、最小化贴边）
3. **T3（半天）**：弹窗双状态卡 + 未注入时禁用主按钮
4. **T4（1 天）**：设置页锚点导航 + 卡片分组 + 置信度滑块 + 交卷二次确认
5. **T5（半天）**：单题模式（视口判定）+ 快捷键 + 连续失败自愈

每步都能独立交付，不必等整套做完。
