# 静答 QuietAnswer · 极简黑白设计方案（选定风格）

> 在 `DESIGN.md` 基础上改为**纯黑白灰**。核心原则：**没有颜色可用，所以用形状、字重、留白来传达状态。**

---

## 一、色彩：只有灰阶

| 语义 | 值 | 用途 |
|---|---|---|
| 纯黑 | `#000000` | 页面底 / 遮罩 |
| 面板 | `#0C0C0E` | 面板背景 |
| 面板浮层 | `#141417` | 弹窗、卡片 |
| 悬停 | `#1C1C20` | hover / 选中行底色 |
| 描边-强 | `rgba(255,255,255,.16)` | 输入框、主按钮边框 |
| 描边-弱 | `rgba(255,255,255,.08)` | 分割线、卡片边 |
| 主文字 | `#FFFFFF` | 标题、正文 |
| 次文字 | `#9A9A9F` | 说明、署名 |
| 三级文字 | `#5E5E64` | 时间戳、占位符 |
| 反色 | `#000000` / `#FFFFFF` | 主按钮：白底黑字 |

浅色模式：`#FFFFFF` 底、`#FAFAFA` 浮层、`#0A0A0A` 文字、`rgba(0,0,0,.10)` 描边。

**没有任何彩色**。唯一的"高亮"是纯白填充 + 反色文字。

---

## 二、状态怎么表达（关键）

没有红绿黄，状态全靠**形状 + 字重 + 符号**：

| 状态 | 表达 |
|---|---|
| 空闲 | 空心圆 `○` + 40% 白 |
| 运行中 | 圆环 + 呼吸动画（透明度 1 → .35 循环 1.6s） |
| 完成 | 实心圆 `●` + 100% 白 |
| 出错 | 圆环里一道斜杠 `⊘`，并让该行文字改为**下划线** |
| AI 判断"对" | 行首 `√`，正文用 100% 白 |
| AI 判断"错" | 行首 `×`，正文用 100% 白 + 左侧 1px 竖线标记 |
| 警告（低置信度） | 行首 `!`，正文 `#9A9A9F` |

进度用**等宽数字** `3/31`，比百分比更克制：

```
静答   3/31 ●
```
环形进度：1px 白色弧线画在 `rgba(255,255,255,.12)` 轨道上。

---

## 三、排版

| 层级 | 规格 |
|---|---|
| 面板标题 | 12 / 600 / 字距 0.04em |
| 正文 | 12 / 400 |
| 说明·署名 | 11 / 400 / `#9A9A9F` |
| 数字·日志 | 11 / 400 / `ui-monospace` |
| 大标题（设置页） | 15 / 600 |

**留白加倍**：内边距 16（原 12），卡片间距 12，行高 1.7。
**圆角收敛**：控件 6，面板 10（原 10/14）。黑白风格里大圆角会显"软"。
**边框代替阴影**：只用 1px 描边分层，不用投影；唯一阴影是浮层 `0 12px 32px rgba(0,0,0,.55)`。

# 十、圆滑化修订（最终稿）

黑白 + 圆滑是最终方向。要点不是"把圆角调大"，而是**四件事一起改**，否则只是"大圆角 + 硬线条"，更难看。

## 10.1 半径体系

| 元素 | 半径 | 说明 |
|---|---|---|
| 面板（HUD / 弹窗） | **18** | 主容器，圆润的主体感 |
| 卡片 / 日志区 / 状态行 | **14** | 次级容器，比面板小一档 |
| 控件 / 输入框 | **12** | 按钮、输入框、下拉 |
| 按钮 / 胶囊 / chips | **pill（全圆角）** | `border-radius: 999px`，圆滑感的最大来源 |
| 图标容器 | 34%（`s*0.34`） | 与面板比例协调 |

> 规律：**容器越大圆角越大，控件一律走 pill**。6px 那一版全部作废。

## 10.2 分割线：不通栏

- 原来：`border-bottom` 通栏 1px —— 视觉上把面板"切"成几块，硬
- 现在：**两端内缩 16px** 的 1px 线，或干脆用 12 圆角卡片分组

```css
.cxai-divider {
  height: 1px;
  margin: 0 16px;              /* 两端内缩，不碰边 */
  background: rgba(255,255,255,.10);
}
```

## 10.3 阴影：两层

黑白界面没有色彩分层，全靠阴影托住"浮起"的感觉：

```css
box-shadow:
  0 18px 48px rgba(0,0,0,.55),   /* 大范围环境阴影 */
  0 2px 8px  rgba(0,0,0,.30);    /* 贴边接触阴影 */
```

浅色模式下改为 `0 18px 48px rgba(0,0,0,.14), 0 2px 8px rgba(0,0,0,.06)`。

## 10.4 描边：只压边，不切割

- `1px rgba(255,255,255,.10)`，颜色**必须很淡**
- 深色底不要用纯黑 `#000`，用 `#0D0D0F`；否则 1px 描边完全看不见，面板像个洞
- 浅色底用 `1px rgba(0,0,0,.12)`

## 10.5 间距

| 位置 | 值 |
|---|---|
| 面板贴边（HUD 距屏幕边） | 16 |
| 面板内边距 | 16 |
| 组内元素 | 8 |
| 组之间 | 16 |
| 按钮高度 | 主 36 / 次 32 |

## 10.6 控件形态

| 控件 | 形态 |
|---|---|
| 主按钮 | 黑底白字（HUD）/ 白底黑字（浅色界面），**pill** |
| 次按钮 | 透明底 + 1px 描边，**pill** |
| 模式切换 | pill chips：当前项实心反色，其余描边 |
| 输入框 | 透明底 + 1px 描边 + 半径 12，聚焦时描边 `rgba(255,255,255,.28)` |
| 日志区 | 凹陷卡片：更深的底 `#09090A` + 半径 14 |
